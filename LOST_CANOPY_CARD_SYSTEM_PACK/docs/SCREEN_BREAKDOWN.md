# Screen Breakdown

## 1. Jaguar Encounter
**Típus:** animal encounter

Scene: survivor + jaguar az ösvényen.

Kártyák:
- Use Torch — item cost, safe
- Use Spear — risky combat
- Throw Meat — item cost, bypass
- Retreat — mindig elérhető, time cost

Tanulság: ez a fő referencia arra, hogyan kapcsolódik az inventory a choice rendszerhez.

## 2. Crafting Cards
**Típus:** recipe selection

A bal oldali nagy panel a kiválasztott receptet mutatja, jobb oldalon recipe card lista.

Példa:
- Stone Axe
- Torch
- Fishing Rod
- Water Filter
- Rope Trap

A craftolt item ne csak stat bonuszt adjon, hanem új card choice-okat és jobb loot poolt is nyisson.

## 3. Camp Build / Upgrade
**Típus:** persistent progression

Build cardok:
- Shelter Roof
- Storage Crate
- Leaf Bed
- Rain Collector
- Drying Rack
- Workbench

A megépített objektum fizikailag jelenjen meg a camp scene-en.

## 4. Herb Patch
**Típus:** gathering/resource event

Kártyák:
- Gather Carefully
- Use Knife
- Take Everything
- Leave It

A jobb tool nagyobb yieldet és jobb herb loot poolt ad.

## 5. Plane Wreck
**Típus:** salvage/story event

Kártyák:
- Search Cockpit
- Search Cargo
- Cut Wiring
- Leave

A különböző choice-ok más loot poolból húznak és időt fogyasztanak.

## 6. Night Event
**Típus:** camp danger event

Kártyák:
- Check Outside
- Add Wood to Fire
- Use Torch
- Stay Quiet

A night eventek a camp gear és aktuális resource állapotát használják.

## 7. Fishing
**Típus:** activity + minigame

Belépési kártyák:
- Bait
- Fish
- Leave

A `Fish` egy rövid timing minigame-et indít.

## 8. Blocked Path
**Típus:** obstacle event

Kártyák:
- Cross
- Look for Another Way
- Return

Később gear-alapú negyedik opció is megjelenhet, pl. `Use Rope`.

## 9. Home Camp
**Típus:** hub

A fő action cardok:
- Forage
- Craft
- Build
- Explore

Innen indul minden loop.

# Gameplay Loop + MVP Minigame-ek

## Core loop
**Camp → Choose Goal → Travel/Event → Minigame → Loot → Push deeper / Return → Craft/Build → Night → Next Day**

A játék élvezetének három pillére:
1. **tervezés** — mire van szükségem ma;
2. **skill** — rövid minigame-ek;
3. **kockázat** — továbbmegyek vagy hazaviszem a lootot.

## 1. Fishing
Kétlépcsős, kb. 5–10 másodperc.

### Hook phase
Kapáskor rövid reakcióablak. Jó időben tap → hooked.

### Reel phase
Mozgó indicator / safe zone. A játékos tap/hold segítségével a zónában tartja.

### Reward
- Fail → bait lost
- Good → small/medium fish
- Perfect → large fish + rare catch chance

Jobb rod:
- nagyobb safe zone
- jobb fish loot table
- rare catch unlock

## 2. Hunting
Célpont mozog. A játékos időzíti a spear throw-t.

- Miss → nincs loot / danger nőhet
- Hit → meat
- Perfect → több meat + hide chance

Jobb spear:
- nagyobb hit window
- magasabb meat yield
- ritkább hide / trophy loot

## 3. Wood Chopping
Mozgó timing marker, 2–4 gyors ütés.

- Miss → durability loss
- Good → wood
- Perfect → extra wood

Jobb axe:
- kevesebb hit szükséges
- magasabb yield
- hardwood / resin unlock

## 4. Foraging
Rövid, 5–10 másodperces választós játék.
Megjelenik több növény, a player kiválasztja mit szed le.

Loot példa:
- berry
- fiber
- herb
- mushroom
- medicinal herb

Kockázat: poisonous plant.
Jobb knife/machete több és jobb növényt nyit.

## 5. Ruins Puzzle
10–20 másodperces egyszerű pattern / symbol puzzle.
Példák:
- 3 forgatható kőlap
- helyes szimbólumsorrend
- 3x3 simple path

Reward:
- rare component
- map fragment
- beacon component

## Nem minigame minden
A survival döntések maradjanak gyorsak. Víz tisztítás, craft, inventory, base build főleg döntés és resource management.

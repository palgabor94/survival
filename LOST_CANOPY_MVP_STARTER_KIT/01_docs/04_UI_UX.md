# UI / UX Spec

## Base Screen
Top:
- Lost Canopy logo
- Health / Water / Food / Sanity
- Wood / Stone / Fiber quick resources

Upper-left:
- Day + weather
- current objective

Bottom primary actions:
- FORAGE
- CRAFT
- BUILD
- EXPLORE

Secondary:
- Inventory
- Map

## Explore Map
- current camp node
- Riverbank
- Fishing Pond
- Plane Wreck
- Ancient Ruins
- dotted travel routes

## Event Screen
Main illustration + short event copy + 2–3 large decisions.
Decision cards should communicate risk visually when possible.

## Craft Screen
Selected item + recipe costs + item benefit + list of recipes.
The player should instantly understand:
- can I craft it?
- what improves?
- what new loot does it unlock?

## Inventory
MVP: 8 carried slots.
Camp storage upgrades can raise practical storage to 12+.

## Feedback
Every action needs immediate feedback:
- floating `+2 Wood`
- stat change animation
- newly unlocked recipe/location toast
- camp upgrade visual transition

# Camp Progression Prompt

Generate the SAME jungle clearing from the SAME high isometric camera angle and SAME style as the master reference.
Only change the camp progression state.

Tier 0: leaf lean-to, bedroll, campfire, lantern, one crate.
Tier 1: stronger shelter, storage, simple workbench, improved bed.
Tier 2: partial wooden platform, water collector, drying rack, cooking area, more storage.
Tier 3: established refuge, larger platform, advanced workbench, proper bed, radio/beacon corner, organized storage.

Each tier must retain recognizable structures from the previous tier so progression feels additive.

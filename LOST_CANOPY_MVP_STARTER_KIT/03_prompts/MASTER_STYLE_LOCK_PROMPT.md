# Master Art Style Lock Prompt

Use the provided Lost Canopy master reference image as the PRIMARY style reference.

Preserve the same exact visual language:

- simplified low-poly-inspired 2D illustration

- readable silhouettes
- lush but simplified jungle foliage
- warm ochre/sandy ground

Do not reinterpret the style. Do not increase detail density. Do not change the camera angle. Do not add realistic surface textures. The asset must look like it belongs to the exact same mobile game and asset pack as the reference.

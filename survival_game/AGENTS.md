# Artwork references

When generating any Lost Canopy image that includes the player character, always attach `design/references/explorer_character_master_v1.png` as the character identity reference alongside the scene/style reference. Preserve the character's design while varying pose and location. Details: `design/ART_DIRECTION.md`.

Current jaguar camp-style trials use the camp artwork for style and camera, plus the canonical character sheet. The old detailed jaguar artwork is not a reference for these trials. Keep trial outputs in `design/jaguar-camp-style-test/`; do not replace production assets or wire previews into the game unless the user requests integration.

The active camera reference for new scenes is `design/jaguar-camp-style-test/jaguar_camp_style_v3.png`: match its moderately elevated three-quarter view, not a steep 65–70 degree overhead camera. Attach the canonical character sheet too. The user authorized integration of the approved encounters and listed world scenes on 2026-10-13; see `assets/art/camp_style_refresh_manifest_v1.json`.

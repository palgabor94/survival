# Egységes kártya, eltérő információmennyiség

Három 112×172-es kártya: Torch, Stone Axe, Emergency Beacon. A kép mindig 108×72 (3:2), a címhely és a rövid információ/állapotsáv mérete közös. A Beacon hat alapanyaga, a táborfeltétel és a hiányzó komponens a külön részletezőben szerepel; nem a kártyán. A receptköltségek a recipes.json alapján készültek, a készletek illusztratívak.

A hiányzó Beacon Core miatt az elkészítési gomb inaktív lenne. Hosszabb tartalomnál a részletező görgethető, a kártyák és a fejléc helyben maradnak. Koncepció, nincs integrálva.

Render: `python3 design/parchment-card-details-v1/render.py`.

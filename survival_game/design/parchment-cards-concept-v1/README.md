# Pergamenes UI – játékstílushoz igazított koncepció

A felhasználó referenciafotójából a pergamenkártyák és kör alakú statjelzők irányát vettük át. A tábor és a karakter a játék meglévő egyszerűsített festett/facettált art stílusát követi. Nincs játékba kötve.

- camp-parchment-game-style-v1.png: teljes tábori látványterv.
- stat-health-v1.png, stat-water-v1.png, stat-food-v1.png, stat-sanity-v1.png: külön 1254×1254-es RGBA ikonok, tényleges átlátszósággal.
- index.html: megtekintő galéria.
- PROMPTS.md: teljes promptkészlet, built-in image_gen.

A generált körök optikai mérete és pereme kissé eltér; végleges bekötés előtt egységes méretre kell igazítani. A mockup generált kép, nem futó UI screenshot.

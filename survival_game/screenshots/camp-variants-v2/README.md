# Lost Canopy — 3 × 3 shelter-változat

2026-10-12. [Mobilgaléria és teljes háttérképek](index.html).

Tier 1, Tier 2 és Tier 3 egyaránt három képet használ: a karakter a tűznél melegszik, az ágy szélén pihen vagy a munkaasztalnál dolgozik. Az eredeti tábor szerkezete, kamerája és stílusa megmaradt.

A nappali tábor 30 másodpercenként, 650 ms áttűnéssel vált, játékmeneti költség nélkül. Nyitott popup/route, pending action/report, háttérbe tett app, éjszaka, vihar vagy csökkentett animáció mellett nem vált. A Tier 0 saját alapképe megmarad.

A 01–09 PNG valódi tábori UI, 390 × 844 logikai méret, 780 × 1688 PNG. A kezdő póz a képhez rögzített; a működő ciklust és szüneteltetést widgettesztek ellenőrzik.

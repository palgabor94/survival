# Bekötött minijátékok · gameplay képek

[20 kép, sorrendben](index.html) · [Bekötési dokumentáció](../../design/minigames-v1/IMPLEMENTATION.md).

Tényleges production Flutter widgetek és GameEngine-eredmények, előkészített induló állapottal. A mobilképek 780×1688 PNG-k; a fekvő nézetek 1688×780. A visszajelzéseket a tényleges START/ütés gombokkal rögzíti az exporter.

Újrarenderelés az alkalmazás könyvtárából:

```sh
LOST_CANOPY_CAPTURE_MINIGAMES=1 python3 screenshots/tools/capture_unified_ui.py
```
